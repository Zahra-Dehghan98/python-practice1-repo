# Python Exercise - Password Strength Checker

A Python program that checks password strength based on security rules.

## Features:
- Username and password input validation
- 8 security checks including length, character types, and common passwords
- Password strength scoring (1-8 points)
- Security level assessment (Very Weak to Strong)
- Detailed feedback on failed checks

## Security Checks:
1. Minimum 8 characters length
2. At least one English letter
3. At least one special character
4. At least one uppercase letter
5. Not identical to username
6. Not case-swapped username
7. Not special-character version of username
8. Not in common passwords list
